# Activité Pratique N°1 – Mise en œuvre de PyTorch

## 📌 Présentation

Ce projet a été réalisé dans le cadre de l’**Activité Pratique N°1** et porte sur la découverte et la mise en œuvre du framework **PyTorch**.

L’objectif est de se familiariser avec l’environnement PyTorch et avec les principales fonctionnalités utilisées en **Machine Learning** et **Deep Learning**.

## 🎯 Objectifs

- Installer et configurer l’environnement PyTorch
- Découvrir le framework PyTorch
- Manipuler les tenseurs (`Tensor`)
- Effectuer des opérations sur les tenseurs
- Utiliser PyTorch avec Python
- Comprendre les bases nécessaires à la création de modèles de Deep Learning

## 🛠️ Technologies utilisées

- Python 3.11
- PyTorch
- Visual Studio Code
- Jupyter Notebook
- Git
- GitHub

## ⚙️ Installation

### 1. Cloner le dépôt

```bash
git clone https://github.com/khalid-jpg/-Activit-Pratique-N-1.git
```

### 2. Accéder au projet

```bash
cd -Activit-Pratique-N-1
```

### 3. Créer l'environnement virtuel

```bash
python -m venv .venv
```

### 4. Activer l'environnement virtuel sous Windows

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Installer PyTorch

```bash
pip install torch torchvision torchaudio
```

## ▶️ Exécution

Le projet peut être exécuté à l'aide de **Visual Studio Code** ou de **Jupyter Notebook**.

Après l'activation de l'environnement virtuel, il suffit d'exécuter les fichiers et notebooks présents dans le projet.
